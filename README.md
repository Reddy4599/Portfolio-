# Medagam V S Manjunadha Reddy - Developer Portfolio

A modern, interactive portfolio built with React, Vite, Tailwind CSS, Framer Motion, and Three.js. It presents my software engineering, AI/ML, backend, certification, patent, and project experience in one polished web experience.

## Highlights

- Responsive single-page portfolio with smooth section navigation.
- Animated hero section with rotating role subtitles and 3D visual elements.
- Project showcase for AI/ML, agentic AI, IoT, and backend systems.
- Timeline for education and internship experience.
- Certification and patent sections with downloadable supporting documents.
- Contact section with resume, email, GitHub, and LinkedIn links.

## Tech Stack

- **Frontend:** React, Vite, Tailwind CSS
- **Animation:** Framer Motion
- **3D:** Three.js, React Three Fiber, Drei
- **Deployment:** Vercel-ready configuration

## Getting Started

```bash
git clone https://github.com/Reddy4599/Portfolio-.git
cd Portfolio-
npm install
npm run dev
```

The app will run locally at the Vite development URL shown in your terminal, usually `http://localhost:5173`.

## Production Build

```bash
npm run build
npm run preview
```

## Project Structure

```text
src/
  assets/          Portfolio data and content
  components/      Reusable UI components
  sections/        Page sections such as Hero, About, Projects, Timeline, Contact
public/
  certificates/    Certification and internship PDFs
  images/          Profile and static images
```
